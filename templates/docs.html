Introduction

WanX is an original programming language created by JagX and JRILICENSE. It uses a completely unique vocabulary and does not copy Python, JavaScript, C++, or other major languages.

It is designed to be powerful enough to build systems, applications, game logic, and AI foundations.

Basics

:: Comments start with ::
pulse "Hello WanX"

forge x = 42
forge name = "Aria"
pulse name + " is " + str(x)

Control Flow

forge score = 78

probe score >= 90 path
    pulse "Excellent"
shadow
    probe score >= 70 path
        pulse "Good job"
    shadow
        pulse "Keep going"
    close
close

forge i = 0
orbit i < 5
    pulse i
    forge i = i + 1
close

Functions

weave add(a, b)
    emit a + b
close

pulse add(10, 32)

weave greet(who)
    pulse "Hello, " + who
close
greet("Learner")

Lists & Vaults

forge nums = [1, 2, 3, 4]
pulse nums[0]
push(nums, 5)
pulse len(nums)

forge player = vault {
    "name" : "Hero",
    "hp" : 100
}
pulse player["name"]
player["hp"] = 90

Classes (form)

form Player
    weave init(name, hp)
        core.name = name
        core.hp = hp
    close
    weave status()
        pulse core.name + " has " + str(core.hp) + " HP"
    close
close

forge p = new Player("Aria", 100)
p.status()

Useful Built-ins

  • Math: abs, sqrt, pow, sin, cos, floor, ceil, min, max, sum, pi, e
  • Lists: len, push, pop, slice
  • Strings: upper, lower, split, join, replace, contains, trim
  • Vaults: keys, values, has
  • Game: distance, collide
  • Other: type, str, num, random, randint, time, sleep, fetch, tojson, fromjson
